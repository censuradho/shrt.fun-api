# Copilot Instructions - MV API

Você está trabalhando com uma API de encurtador de URLs usando Clean Architecture + DDD.

## Estrutura Arquitetural

### Padrão de Módulo (Bounded Context)
Cada módulo segue: `modules/<nome>/{index.ts, plugin.ts, application/, domain/, infra/, presentation/}`

Cada camada tem responsabilidades específicas:
- **Domain**: Lógica pura, interfaces, modelos (sem dependências externas)
- **Application**: Use Cases, DTOs, orquestra domain
- **Infrastructure**: Implementações concretas (Repositories, Services)
- **Presentation**: Controllers, Routes, Factories (HTTP adapter)

### Fluxo de Requisição
```
routes.ts → controller → use case → repository → database
     ↓
  [validação Zod]        [lógica de negócio]  [acesso a dados]
```

## Convenções Obrigatórias

### Naming
- Classes: `PascalCase` (UserRepository, UpdateUsernameUseCase)
- Interfaces: Prefixo `I` + PascalCase (IUserRepository)
- Functions/methods: `camelCase` (getUser, updateUsername)
- Files: `kebab-case` (user-repository.ts, update-username.use-case.ts)
- Constants: `UPPER_SNAKE_CASE` (MAX_SIZE, JWT_SECRET)

### Dependency Injection
- Use constructor injection sempre
- Implemente factories em `presentation/factories/`
- Padrão factory: `make<NomeClasse>()` ex: `makeUserController()`

### Error Handling
- Erros esperados: `throw new AppError(message, { status, code })`
- Validação: `schema.parse(data)` com Zod
- Handler global em `main/error-handler.ts` gerencia tudo

### Validação
- DTOs com Zod em `application/dtos/`
- Use `z.object()` para schemas
- Valide sempre no início de use cases

### Testes
- Nomeie: `should <ação> when <condição>`
- Mock apenas dependências, nunca o código testado
- Tests ao lado: `*.spec.ts`
- Use fixtures/factories para dados de teste

## Tecnologias e suas responsabilidades

| Tech | Responsabilidade | Localização |
|------|-------------------|------------|
| Fastify | Framework HTTP | `main/app.ts` |
| Zod | Validação de input | `application/dtos/` |
| Prisma | ORM/Database | `infra/database/`, `prisma/schema.prisma` |
| ioredis | Cache distribuído | `infra/cache/`, `infra/http/plugins/redis.ts` |
| JWT | Autenticação | `@fastify/jwt`, middleware via `app.authenticate` |
| Supabase | Auth externa | `infra/auth/` |

## Ao Criar Novo Módulo

1. Crie estrutura base: `domain/`, `application/`, `infra/`, `presentation/`
2. Defina **interface** em `domain/repositories/IxyzRepository.ts` (contrato)
3. Implemente **repository** em `infra/repositories/xyz.repository.ts`
4. Crie **use cases** em `application/use-cases/`
5. Crie **DTOs** em `application/dtos/` com validação Zod
6. Implemente **controller** em `presentation/controllers/`
7. Crie **factory** em `presentation/factories/make<Nome>Controller.ts`
8. Defina **rotas** em `presentation/routes.ts`
9. Exporte como **plugin** em `plugin.ts` e `index.ts`
10. Registre no `main/app.ts`: `app.register(xyzModule, { prefix: '/xyz' })`

## Padrões Específicos

### Repository (Abstração de Data)
```typescript
// domain/repositories/IUserRepository.ts - Interface (contrato)
export interface IUserRepository {
  create(input: CreateUserEntityDto): Promise<string>;
  findById(id: string): Promise<UserModel | null>;
}

// infra/repositories/user.repository.ts - Implementação
export class UserRepository implements IUserRepository {
  constructor(private readonly prisma: PrismaClient) {}
  async findById(id: string) { return this.prisma.user.findUnique({...}) }
}
```

### Use Case (Orquestração)
```typescript
export class GetUserUseCase {
  constructor(
    private readonly userRepository: IUserRepository,
    private readonly cache: CacheGateway,
  ) {}

  async execute(id: string): Promise<UserModel> {
    // Валидação de negócio
    // Lógica orquestrada
    // Retorna resultado
  }
}
```

### Controller (HTTP Handler)
```typescript
export class UserController {
  constructor(private readonly getUserUseCase: GetUserUseCase) {}

  async getUser(request: FastifyRequest, reply: FastifyReply) {
    const { id } = request.params // Extract input
    const user = await this.getUserUseCase.execute(id) // Call use case
    return reply.status(200).send(user) // Send response
  }
}
```

### Routes (HTTP Definition)
```typescript
export async function registerUserRoutes(app: FastifyInstance) {
  const controller = makeUserController();
  
  app.get<{ Params: GetUserParamsDto }>(
    '/:id',
    { 
      schema: { params: GetUserParamsDto },
      onRequest: [app.authenticate], // Middleware
    },
    (req, reply) => controller.getUser(req, reply),
  );
}
```

### Factory (DI Container)
```typescript
export function makeUserController(): UserController {
  const userRepository = new UserRepository(prisma);
  const getUserUseCase = new GetUserUseCase(userRepository);
  return new UserController(getUserUseCase);
}
```

## Cache Strategy
- Use `CacheGateway` para abstrair Redis
- Padrão: Cache-Aside (lazy load)
- Chaves geradas com `CacheKeyBuilder.xxx()`
- TTL padrão: 3600 segundos (1h)

## Autenticação
- JWT guardado via `@fastify/jwt`
- Middleware: `app.authenticate` (decorate)
- Usuário vem em `request.user` após verify
- RBAC: valide `user.plan` no use case

## Logs e Monitoring
- Use `request.log` para logging Pino
- Erros capturados automaticamente em error-handler
- Estruture logs com contexto relevante

## Performance
- Índices no prisma: `@@index([campo])`
- Cache em leitura frequente
- Paginate grandes datasets
- Avoid N+1: use include/select no Prisma

## Ao Encontrar Arquivo Desconhecido
1. Procure em `src/` pela estrutura (domain/infra/application/presentation)
2. Identifique a camada pela localização
3. Respeite o fluxo de dependências (domain ← application ← infra ← presentation)
4. Nunca importe up (não faça circular imports)

## Dúvidas Frequentes
- **Onde colocar lógica de negócio?** → `domain/services` ou `application/use-cases`
- **Quando criar novo módulo?** → Quando tem bounded context claro (user, link, auth)
- **Como fazer testes?** → Mock dependencies via interfaces, nunca o código testado
- **Cache de o quê?** → Leitura frequente, computada, ou custosa (geoloc, analytics)
